# November reader cards

The November 14 readers packet is the protocol. Run research only through the
counted CPU launcher. Inputs, fitted weights, per-text predictions and caches stay
under `.local`; only aggregate receipts belong in `engine/validation`.

`envent.py` implements the commissioned fixed 1,200-report test. Development is
the lowest SHA-256 tenth of the other writers. This is **not** a writer-disjoint
test: the supplied preflight's 5,400/1,200 split shares 628 test reports' writers
with training. Reproduction retains that split and explicitly records overlap.
Cards specifying writer holdouts must use separate grouped splits.

`metrics.py` reports fixed-label macro-F1, writer-cluster intervals, calibration,
selective accuracy, neutral recall and false-neutral rates. Missing external
nothing-here checks leave B3 pending and prevent pack creation. No benchmark
changes the live reader, its default precision, or any scientific admission.

`acquire.py` is a separate explicit download operation. It resolves a model
revision, records the license as read, saves only local non-executable model
files and hashes every downloaded file. Inference uses local-only loading.

The immutable supplied preflight is reproduced by `scripts/engine-readers-job.py`
in fresh output directories. It shares the original single-scoring lock and
counted host slots, retains exact native identity and releases only its own leases.
