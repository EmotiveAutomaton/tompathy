# Release notes

## 0.2.0-dev.1 — unreleased development toward 0.2

Chrome build 0.1.1, display label “0.2 development 1”. The published 0.1 beta stays unchanged.

- Three-column teardrop icon: a short list, two middle blocks and one soft tip.
- Direct hierarchy selection follows the pointed visual branch; unused later reels fade on shorter paths. Page selection still preserves all explicitly supplied alternatives.
- Curved brick intersections remove missing wedges at the shared rounded back.
- Expanded reels close outside their actual boxes with a small gap allowance; scrollbars stay hidden during expansion.
- Double-click anywhere in the active page/reader to release selection.
- Two example order-uncertainty squiggles, backed by optional validated contract 1.5 sibling groups. Older packets remain readable.
- Free context collection: byline, explicit profiles, one-hop linked pages/feeds, bounded cache, dated source timeline, undated facts, coverage and brief export. No model, paid search or automatic inference.
- Public development workflow and proposed 0.2 completion checklist in `docs/VERSIONING.md`.
- Chrome review launcher discards stale connection metadata before a fresh launch, fixing an observed restart timeout.

## 0.1 beta — 12 October 2026

The first public frontend preview consolidates the private alpha iterations.

- Three linked views: Current attention; Expertise, Habits, and Process; Core values.
- A shared rounded teardrop back, inward-curving shoulders, soft tips and branch-specific dot arcs.
- Reels expand upward in place over the dimmed hierarchy; sentence and node locks remain stable.
- Author selection, nested context controls, compact Color scheme controls, Help and reading import/export.
- Optional bounded author-link retrieval and unauthenticated linked GitHub profiles.
- Portable HTML readings, supplied-result validation, revision retention and repeatable Chrome QA.
- MIT licensing, dependency notices and a small installable ZIP.

Agent search, author-like models, word-level analysis, Global and value search remain planned or interface previews. No live inference backend is connected. Example interpretations are fictional and hand-authored.
