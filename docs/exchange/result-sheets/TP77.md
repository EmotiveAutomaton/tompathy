# TP77 · Agreement between readers

The original roster contains 51,557 sentences with readings from B and W. C read the 5,014-sentence Q11 subset. For each pair we count jointly valid answers, each reader’s unmatched answers and missing answers. The public tables show observed counts with B first for B/W and B/C, and W first for W/C. They report unweighted Cohen’s kappa for change, timing and whose situation changed. The timing and whose tables include the no-change category. The original two sources also receive separate tables.

The roster-wide B/W kappa sets the status used by the cards. At 0.60 or above the mark is usable. From 0.40 up to 0.60 it supports descriptions. Below 0.40, or where kappa is undefined, the studies withhold the dependent comparisons. Intervals resample whole writers within the original source identities. New-source and standing marks receive their own checks as their jobs return.
