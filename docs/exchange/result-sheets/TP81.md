# TP81 · Reliability ceilings for the TP63 trait comparison

The study uses the original 6,600 Crowd-enVENT reports from 2,379 writers. Both builds receive the same input arrays, fixed random selections and signed TP63 interval endpoints. Each computes its own feeling adjustment, variance components, item scores, split halves, rotated reliability bands, ceilings and decisions. The larger absolute endpoint gives the conservative upper bound for either sign.

Seed 23 fixes 2,000 whole-writer draws and 50 within-writer splits; duplicate draws represent separate sampled writers. The assigned-feeling adjustment uses the original report set, as in TP63. An odd-sized split assigns the extra report to the second half. The split-half statistic averages the 50 Spearman–Brown corrected Pearson correlations. A trait pair is excluded for that writer if either reported item is missing or inconsistent across her reports, using the original TP63 rule. For ceiling arithmetic, a nonpositive item correlation gives zero reliability. The untruncated correlation is reported. When a ceiling is zero, the bound is 1. An unattainable target of 0.30 has no finite report count.

The retest comparison uses the packet's mean of 0.72, with 0.62 and 0.77 as sensitivities. Reader worry has no rotated head in its own encoder. The independent builds must match to 0.001 on numeric fields and exactly on verdicts before a result lands. Registered guesses are at least 73 and more than 100 of 145 item-based ceilings below 0.20.

Limit: Reliability here is agreement across a writer's few reports, each written to an assigned feeling, and a writer with one report adds nothing to the within-writer variance estimate. The inventory has two items per trait.
