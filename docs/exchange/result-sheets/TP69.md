# TP69 · Competence, Respect and acceptance by assigned word

The comparison uses the common chat reports with valid values for B’s goal support, own responsibility and own standards. Each component is standardized on this roster. Their mean is the existing Competence stand-in. Respect is the mean of status, approval, competition and honor. Acceptance is the tag stored as belonging.

For each of 32 assigned words, the table gives each column’s mean and its lift over the other words in source standard deviations. Intervals resample whole writers 2,000 times, using the same draws for all columns. The paired differences between lifts are compared with half a standard deviation. The goal-support line reports whether things went the writer’s way in B’s reading. The trained linear Respect average also receives 1,000 isotropic and 1,000 rotated controls on the same reports. The descriptive tag columns use the saved probabilities to preserve TP59’s scale.

An interval containing zero leaves an individual rise unresolved. This word-level comparison informs the curator’s choice about the two display rows.
