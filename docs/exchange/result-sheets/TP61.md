## How the highest-need comparison is measured

Part (a) uses the 5,409 writers with openings in both TP46 date halves. Following the packet’s supplied simulation, each linear head is standardized across the contributing openings. Repeated openings count once per occurrence. The two author means use the same centering and scale. TP46’s original comparison used transformed scores and remains a separate measurement.

The seven trained groups keep TP46’s sizes of 1, 3, 2, 1, 5, 1 and 4. The legacy belonging tag is reported as acceptance. Romance and independence have no trained group assignment. For each of 1,000 sets in each control family, a separate fixed permutation of the 19 heads fills groups of the same sizes without replacement. Its seed uses the first eight bytes of the SHA-256 of `TP61:groups:<family>:<zero-based set index>`, read big-endian. Constant directions are excluded before averaging a group. A completely empty group makes that comparison unavailable.

Each writer contributes one pair of highest-scoring groups. Ties share credit equally. Random dealing has an exact expectation given by the dot product of the two halves’ group frequencies. The primary statistic is observed repeat minus that expectation. Both quantities are recomputed for each of 2,000 whole-writer bootstrap draws. The registered comparison uses the central 95% of the rotated control sets. A result inside that band provides no equivalence margin.
