# TP62 · Assigned words and writer identity

The WORD test asks whether 29 linear outputs identify the assigned emotion on chat situations from held-out writers. The WRITER test asks whether they identify a returning writer on texts about a different set of assigned emotions. Both tests use EmpatheticDialogues under its research-only CC BY-NC terms. The registered science requires all 200 isotropic sets and all 200 rotated sets.

## Choices fixed before fitting

- The 29 trained outputs are the nineteen tag heads, the nine channel heads used on chat, and the separate PRIDE head. Saved ordered IDs and the original ten channel probabilities are checked before fitting. A constant output is omitted from both trained and random sets.
- WORD uses five writer-disjoint folds, assigned by sorting the original writer keys on a seeded hash and dealing them cyclically. The statistic is the mean of the five fold accuracies. Multinomial logistic regression uses LBFGS, C of 1, and up to 2,000 iterations. Each fold uses the training writers to set feature means and scales.
- WRITER uses the original writers with at least eight texts. A seeded split assigns 16 words to profile construction and the remaining 16 to evaluation. A text goes to the nearest profile by cosine distance. Each arm reports the number of authors with support on both sides and the number of test texts. Profile texts set its means and scales.
- Both tests are repeated after excluding texts that contain the assigned word or one of its listed stems. The same fixed case-insensitive token-prefix list applies to every head set. It can exclude additional words that share a prefix. The two versions of the test are reported separately.
- Each control set uses the packet’s seed rule. Rotations use the full square Gaussian QR with positive diagonal. Set zero of each kind and the trained heads form the first measured block. Later blocks reuse those measurements. A partial block cannot determine a control band or settle the prediction.
