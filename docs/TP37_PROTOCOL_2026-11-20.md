# TP37 held-out dimension count

Read only the released writer ID, the prompted feeling word and the 21
event ratings in Crowd-enVENT. Use five writer-disjoint folds. Within each
fold fit the training mean and standard deviation, standardize both sets,
and fit the supplied SVD linear discriminant model. Rank zero uses the
training label frequencies. For each subsequent rank, use the supplied
unpenalized multinomial logistic fit and cap the rank at one less than the
number of words. Use the preflight probability floor of 1e-15. File the
held-out mean log loss for each fold and rank.

The first count is the smallest rank within one standard error of the best
five-fold mean, using the standard error at the best rank. The second is the
last consecutive rank whose paired loss reduction exceeds two standard
errors of that reduction across folds. Both rules start at rank zero and
keep the thresholds in the supplied simulation.

After fixing the two counts, refit one descriptive discriminant basis on
all the reports. Use the first count for the main pair of sheets and show the
second count separately if it differs. Rotate within each kept subspace by
orthogonal varimax of the rating correlations. Orient each axis so that its
largest absolute rating correlation is positive. Order the axes by the
between-word variance of their standardized scores. Give the correlation
with each event rating and the mean standardized score for each prompted
word. Intervals use 2,000 resamples of whole writers with seed 23, conditional
on the fitted axes and their orientation. The analyst can name the closest
channel trigger beside each axis after reading both tables. That name is
descriptive and has no threshold or effect on either count.

The counts are floors on the dimensions this task supports. The simulation
used folds by report. The real evaluation holds out writers. A dimension
can reflect needs, Stress or other structure as well as channels.
