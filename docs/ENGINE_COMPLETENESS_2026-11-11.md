## Repairs made during the completion audit

- Pilot restarts retain the original eight-hour expiry, including downtime.
  A failure or failed model unload leaves an explicit receipt, while preserving
  completed paired documents and measured results.
- The initial Q8 sample spans the seeded category/fold sample rather than the
  first sorted fold. Its projection binds the exact data, sample, hunks, reader
  and measured calls. An initial partial sample cannot qualify the cascade.
- Attention runs bind the raw-source roster and actual reader manifests.
  Replay losses retain private details and public counts; excessive losses stop
  the run visibly. Analysis failures write a stopped receipt.
- EX4 rejects duplicate sessions/word spans and mismatched segmentation.
- Received evidence is marked byte-preserving in Git attributes so Windows
  checkout conversion cannot invalidate delivery hashes.
- Generated reports explicitly use LF line endings, fixing the repository's
  safe-line-ending staging rejection without changing source delivery bytes.
- README, status and privacy descriptions now match the current implementation.
