# TP29 fixed implementation protocol

Frozen November 19 before TP29 marker counts or head results. This implements the
four readings in the new packet; it does not change an earlier failed gate.

Use original ED situations, released GoEmotions consensus labels, and the 6,600
Crowd-enVENT writer labels. Encode with the original pretrained MiniLM, first
128 tokens, normalized vectors. Freeze source IDs/order and model hashes; save
each new vector batch privately. Reuse an exactly bound existing vector table
where available. No held-out ED text trains either source head.

PLAY is logistic amusement versus all other released Go comments. SHAME is
logistic shame versus all other Crowd-enVENT reports. Both use C=3, balanced
classes, max_iter=2000, seed23, no parameter search, and must converge. Source
labels train stand-in heads; these heads do not measure channels directly.

Tokenization is lowercase ASCII word runs, including internal apostrophes.
The fixed fun list is: laugh, laughs, laughed, laughing, laughter, chuckle,
chuckles, chuckled, chuckling, giggle, giggles, giggled, giggling, joke, jokes,
joked, joking, funny, funnier, funniest, humor, humour, humorous, playful,
playfully. The fixed appeasement list is: apology, apologies, apologize,
apologizes, apologized, apologizing, apologise, apologises, apologised,
apologising, apologetic, sorry, awkward, awkwardly, awkwardness, blush,
blushes, blushed, blushing. These are literal markers, not intent annotations.

1. Compare embarrassed and ashamed ED situations. Length adjustment is a
   Poisson log-link rate model with log(word count) as offset and a binary
   embarrassed indicator; equivalently, the ratio of total marker counts per
   total word exposure. Report both counts/exposure, rate ratio and 95% interval.
   Zero counts yield an undefined ratio/interval and cannot pass. Resample
   whole ED writers 2,000 times, recomputing both rates, seed23. Read 1 passes
   only when the fun ratio exceeds 1 and the interval lies above 1.
2. Compare PLAY probabilities between embarrassed and ashamed ED situations,
   standardized by the population SD over these two groups together. Bar .2;
   also report a whole-writer interval. No fitted ED labels enter this contrast.
3. For embarrassed versus every other ED label, fit shame-only and shame+play
   logistic calibrators with C=3 in five writer-disjoint folds (writers sorted
   by SHA-256(seed23, writer), distributed round-robin). Standardize each
   probability column using fitting writers only. Report pooled held-out AUCs
   and their paired difference, with 2,000 whole-writer fixed-forecast resamples.
   Require gain >=.02, lower interval >0 and both coefficients positive in
   every held-out fold. This conservative sign rule avoids choosing a favorable
   fold. No claim of a separately held-out source for the ED calibration step.
4. On released Go comments, compare amusement co-label proportions for
   embarrassment versus remorse, preserving overlapping labels. Report both
   denominators, the difference and a whole-author interval; unknown authors
   are distinct comments. Read 4 uses the packet's point-order criterion.

Intervals are percentile 2.5/97.5. An interval needs at least 95% finite draws.
For the two binary AUCs, resample the same writers and reuse fixed forecasts.
No bootstrap refits or corpus-level causal claim is made. Published sources
have distinct elicitation and annotation processes; cross-source performance
does not establish writer traits. ED remains CC-BY-NC research-only.

The [November 19 owner ruling](TP29_OWNER_RULING_2026-11-19.md) supersedes the
original verdict wording. A requires readings 1, 2 and 3. B requires a higher
appeasement rate with its interval above 1, independent of reading 2. Report
all four A/B combinations using the owner's wording. Reading 4 enters neither
verdict. Undefined measurements stay explicit; no markers, scores or thresholds
change. The running job retains the original protocol pin; its aggregate must
bind the ruling and preserve its original runner verdict before applying A/B.
