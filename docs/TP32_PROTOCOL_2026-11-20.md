# TP32 refusal directions

The November 19 packet supplies both questions and bars. This implementation fixes the following choices before scoring.

Use the pinned 1,445-session public CoAuthor roster and the frozen MiniLM encoder at 128 tokens. A menu counts once when opened. Reopening the same menu adds no second exposure. Count all suggestions in an explicitly dismissed menu as dismissals. An ignored menu contributes exposure only. Verify an acceptance or later edit using the original inserted text. Duplicate indices matching the same inserted text give one acceptance. Exclude unusable episodes. Keep the number of excluded sessions and menus. Repeated offers carry their observed multiplicity.

Center each occurrence on the mean of all offered vectors for its prompt across the census. This uses unlabeled exposures. Within any set of sessions, subtract the centered mean of all offers from each of the centered means of dismissed and accepted texts. The acceptance rate is accepted menus divided by usable opened menus.

Sort each writer’s sessions by SHA-256 of the session ID and assign alternating sessions to halves. Require four sessions overall, 20 dismissed suggestions per half and defined refusal directions. Report the equal-writer mean same-writer cosine minus the mean across different writers in opposite halves. Draw 2,000 whole-writer bootstrap samples with seed 32, excluding pairs with the same original identity from the between-writer term. The lower 95% percentile bound must exceed zero.

For each query session, every candidate’s reference uses only sessions on other prompts. Use the same eligible writers, queries and candidates for both scores. Require defined acceptance and refusal directions, the true writer and at least one competitor. Average absolute rate difference and angular dissimilarity `(1 − cosine)/2` for the acceptance-only rule. The augmented rule averages those two distances and the refusal dissimilarity. Award fractional top-one credit for tied minima. The registered improvement is at least .03 in pooled session accuracy. Report the paired interval from 2,000 whole-writer draws and matching coverage.

Session-level data and embeddings stay private. The result applies to these observed writing sessions. It licenses no person identification or emotional-channel inference.
